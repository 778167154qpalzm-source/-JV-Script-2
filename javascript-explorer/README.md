# مختبر أمثلة JavaScript

موقع تعليمي ثابت يضم واجهة عربية RTL وقائمة جانبية للبحث والتنقل بين أمثلة تفاعلية مستوحاة من موضوعات الصفحات الأولى حتى العاشرة في دليل JavaScript على هرمش.

## المزايا
- واجهة عربية متجاوبة مع الهاتف والحاسوب.
- قائمة جانبية حسب الموضوع مع بحث فوري؛ كل مثال له ملف HTML مستقل ويمكن فتحه مباشرة من الأيقونة الخاصة به.
- حقول مدخلات تتغير حسب المثال.
- معاينة HTML واضحة، وزر تنفيذ وإعادة ضبط.
- تنفيذ alert() كرسالة متصفح حقيقية.
- فتح نافذة/صفحة مستقلة لأمثلة document.write()، مع إبقاء المختبر الأصلي مفتوحًا.
- إظهار الكود التعليمي ورابط صفحة المصدر لكل مثال.
- لا يحتاج إلى خادم خلفي أو قاعدة بيانات.

## التشغيل محليًا
1. فك ضغط المشروع.
2. افتح `index.html` في متصفح حديث.
3. لا يحتاج الموقع إلى تثبيت حزم أو تشغيل خادم. الخط العربي الخارجي اختياري؛ تُستخدم خطوط بديلة إذا لم يتوفر الاتصال.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر وافتح رابط الموقع الذي يظهر في صفحة Pages.

## النسب والمصدر
تُعرض روابط الدروس الأصلية في كل مثال. هذا مشروع تعليمي مستقل وغير تابع رسميًا لهرمش، وشروح الواجهة صيغت بصورة مستقلة. أُضيفت مجموعات الصفحة الرابعة (نظرة عامة على العوامل)، والخامسة (العوامل الحسابية)، والسادسة (عوامل المقارنة). الأمثلة التعليمية صيغت بصورة مستقلة مع روابط إلى صفحات هرمش الأصلية، ولا تدّعي أنها نسخ حرفية أو حصر كامل لكل ما في المصدر.

## ملاحظة تقنية
تُنفّذ أمثلة `alert()` باستخدام رسالة المتصفح الحقيقية. وتُفتح أمثلة `document.write()` في نافذة مستقلة تستخدم `document.write()` فعليًا؛ وذلك لتوضيح سلوكه دون أن يستبدل محتوى صفحة المختبر. قد يحتاج المتصفح إلى السماح بالنوافذ المنبثقة للملف المحلي.


## إضافات الصفحات 7–10
- الصفحة السابعة: أمثلة العوامل المنطقية ومحاكي شامل لـ AND وOR وNOT.
- الصفحة الثامنة: أمثلة العوامل البتّية ومحاكي يجمع AND وOR وXOR وNOT والإزاحات.
- الصفحة التاسعة: أمثلة عوامل الإسناد الحسابية والبتّية ومحاكي شامل.
- الصفحة العاشرة: أمثلة typeof وinstanceof ومحاكي لفحص الأنواع.
- في نهاية كل مجموعة صفحة يوجد مثال مستقل بعنوان «محاكي شامل» يجمع نتائج موضوعات الصفحة في جدول تفاعلي.


## صفحة مستقلة لكل مثال
كل عنصر في القائمة الجانبية عبارة عن رابط حقيقي إلى ملف HTML خاص بالمثال (مثل `start-1.html` و`logical-and.html`). لذلك يعمل التنقل بالنقر، ويمكن فتح رابط أي مثال مباشرة أو تحديث الصفحة، بما في ذلك عند النشر على GitHub Pages. عدد صفحات الأمثلة المُنشأة: 76.
